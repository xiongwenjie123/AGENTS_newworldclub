2. 产品概述 & V2.0迭代目标

 

2.1 产品简介

 

新大陆俱乐部人才选聘系统，面向企业HR/老板，基于资深HR与企业主调研问卷沉淀的面试测评经验，登舰考试（智考） 是V2.0核心新增能力。企业输入招聘需求，系统从官方试卷库自动组卷生成专属考卷，分发候选人作答；提交后后台算法输出八维能力得分 + 21型职业适配判定，给出人才录用参考建议，实现「一句话帮你招对人」。

 

2.2 V2.0迭代目标（增量，存量不动）

 

1. 后台运营侧：官方试卷库手动导入入口，支持批量/单条录入调研得到的测评题目，维护题目标签、能力维度、职业分类。

2. 出题基础算法：基于企业岗位需求，从官方题库筛选、重组生成个性化登舰考卷，附带评测打分标准。

3. 企业HR端：HR录入行业、岗位、用人偏好等招聘需求，一键生成考卷、一键分发至候选人（绑定候选人唯一用户ID）。

4. 应聘者个人端：登舰考试入口，查看分配给自己考卷、在线作答、提交答卷。

5. 测评分析引擎：答卷提交后自动计算八维能力分数，匹配21型职业分类，输出可视化测评报告与录用建议。

6. 所有V1.0原有业务（21席三舱编组、Mission七步闭环、人才画像、团队匹配等）全部保留，不做删除与破坏性修改。

 

2.3 核心业务一句话链路

 

运营后台导入调研题目至官方题库 → HR录入招聘需求 → 出题算法自动筛选组卷生成专属考卷 → HR一键分发到候选人唯一UID → 候选人登录进入登舰入口答题提交 → 测评算法解析答卷 → 输出八维+21型职业测评报告给HR。

4. V2.0新增业务流程：登舰考试（智考）完整流程

 

流程1：运营后台维护官方试卷库

 

1. 运营（项目管理员）登录后台，进入【官方题库管理】页面

2. 单条新增题目 / 批量导入Excel题库（调研问卷产出的测评题）

3. 录入题目元数据：题干、选项、作答类型（单选/多选/开放简答题）、所属八维能力标签、适配21型职业标签、权重分值、评判标准

4. 保存入库，支持编辑、上下线、删除、搜索筛选题库

 

流程2：企业HR录入招聘需求，生成登舰考卷

 

1. HR登录企业后台，进入【登舰智考】模块

2. 填写招聘需求表单：行业、目标岗位、岗位描述、用人要求、岗位优先级、希望考察的八维能力、期望的21职业类型、题目数量偏好

3. 点击【生成专属考卷】，调用出题基础算法

4. 算法读取官方题库，匹配需求标签，自动抽取题目，生成整套考卷+配套评测标准

5. HR预览考卷，可手动增删调整题目；确认后保存考卷（考卷归属该企业账号）

 

流程3：HR分发考卷给应聘者

 

1. HR输入应聘者唯一用户UID，绑定考卷

2. 点击【分发登舰考卷】，系统将考卷关联至该个人用户账号

3. 应聘者收到通知（站内消息）

 

流程4：应聘者作答登舰考卷

 

1. 应聘者（个人用户）登录前端，进入【登舰考试】入口

2. 展示分配给自己的考卷，支持限时作答配置

3. 逐题作答，自动保存草稿；完成后提交答卷

4. 答卷数据入库，触发后台测评分析任务

 

流程5：后台测评算法分析，生成测评报告

 

1. 接收答卷数据，执行测评引擎

2. 计算八大能力分项得分；基于答题特征匹配21型职业适配类别

3. 生成可视化测评报告：能力雷达图、21职业匹配结论、综合录用建议、风险提示（区分实干/嘴炮候选人）

4. HR在后台查看完整报告，导出PDF

 

5. 用户角色扩展（原有角色保留，新增权限子集）

 

1. 平台运营管理员（新增权限：题库管理）：导入、维护官方试卷库，管理题目标签，查看全平台考卷统计

2. 企业HR/企业管理员（新增模块：登舰智考）：录入招聘需求、生成考卷、分发考卷、查看候选人测评报告

#7 核心算法详细设计（可直接编码）

##7.1 出题基础算法（组卷算法）

 

输入：HR招聘需求参数

输出：一套专属考卷（题目列表+评测标准）

 

plaintext  

算法逻辑伪代码

1. 从官方题库过滤：只取出状态=上线的题目池

2. 过滤规则：优先匹配【选中的八维能力标签】，其次匹配【期望21职业标签】

3. 权重打分：每道题匹配标签越多，题目优先级权重越高

4. 按权重排序，抽取N道题目（N=HR填写的题目数量）

5. 多样性约束：保证题型分布均衡，不会全部都是简答题/选择题

6. 输出题目集合，生成考卷元信息，附带每道题对应的评测打分标准

7. 可选：如果匹配题目不足，降低标签严格度，扩大题目池兜底

 

 

参数配置文件： exam-algorithm-config.json ，可调整标签权重系数，无需改代码。

 

##7.2 测评分析算法（答卷解析，八维+21职业判定）

输入：候选人所有作答记录

输出：八维分数，21职业TOP3匹配，综合人才结论

 

1. 八维能力计算：每道题目绑定对应能力维度，按作答结果累加维度分值，归一化0~100分

2. 21型职业匹配：基于各维度能力向量，与预设21类职业能力特征向量做余弦相似度计算，输出相似度TOP3职业

3. 实干/嘴炮特征识别：匹配调研问卷收集的作答特征规则库，标记风险提示

4. 规则库：来自HR/老板调研问卷，可后台持续更新规则，不需要重新部署代码

 

开发说明：向量相似度计算可直接使用开源向量工具，见下方开源组件清单

 

#8 新增数据库表设计（不修改原有V1.0数据表，全部新建）

##表1： exam_official_question  官方题库表

 

sql  

CREATE TABLE `exam_official_question` (

  `id` bigint PRIMARY KEY AUTO_INCREMENT,

  `title` text NOT NULL COMMENT '题干',

  `question_type` varchar(20) NOT NULL COMMENT 'single/multiple/essay 单选多选简答',

  `options` text COMMENT 'json存储选项',

  `judge_rule` text COMMENT '评判标准、参考答案',

  `eight_dim_tags` varchar(255) COMMENT '八维标签逗号分隔',

  `career21_tags` varchar(255) COMMENT '21职业标签逗号分隔',

  `weight_score` int DEFAULT 5 COMMENT '题目权重',

  `status` tinyint DEFAULT 1 COMMENT '1上线0下线',

  `create_time` datetime DEFAULT CURRENT_TIMESTAMP,

  `update_time` datetime DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP

) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

 

 

##表2： exam_paper  HR生成的企业考卷表

 

sql  

CREATE TABLE `exam_paper` (

  `id` bigint PRIMARY KEY AUTO_INCREMENT,

  `paper_name` varchar(100) NOT NULL,

  `demand_json` text NOT NULL COMMENT 'HR招聘需求参数json',

  `question_ids` text NOT NULL COMMENT '选中题目id数组json',

  `time_limit` int COMMENT '考试限时分钟',

  `status` tinyint DEFAULT 1,

  `create_time` datetime DEFAULT CURRENT_TIMESTAMP

) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

#12 非功能需求

 

1. 并发：同时支持至少50用户在线答题

3. 兼容性：PC端优先，适配移动端答题

4. 性能：组卷算法响应 <3s；测评报告异步生成，最长等待10s

5. 数据备份：题库、答卷数据定时备份

 

#13 测试用例（核心功能冒烟测试，开发自测）

#14 风险与降级方案

 

1. 风险：标签匹配题目不足。降级策略：算法自动放宽标签权重，扩大题库范围兜底，依然生成考卷，页面提示HR。

2. 风险：简答开放题自动评判效果有限。降级：算法输出参考判定，报告标注【简答题建议HR人工复核】。

3. 风险：异步报告任务队列故障。降级：提供手动触发重新生成报告按钮，HR可以重试分析。

4. 风险：题库导入Excel格式异常。降级：逐行校验，错误行单独列出，不污染全部导入数据。

python  

# exam_algorithm.py

# 新大陆俱乐部 V2.0 登舰考试：出题组卷算法 + 八维&21职业测评引擎

import json

import numpy as np

import hnswlib



# ===================== 配置文件读取（单独 exam-algorithm-config.json）=====================

CONFIG_PATH = "exam-algorithm-config.json"

def load_config():

    with open(CONFIG_PATH, "r", encoding="utf-8") as f:

        return json.load(f)

ALG_CONFIG = load_config()



# 21类职业预设标准能力向量，从配置读取

career21_vectors = ALG_CONFIG["career21_vector"]

# 八维能力列表

EIGHT_DIM = ["探索力","想象力","理解力","拆解力","执行力","协作力","决策力","守护力"]



# ===================== 模块1：出题基础组卷算法 =====================

def generate_exam_paper(question_pool:list, demand_params:dict):

    """

    :param question_pool: 官方上线题库列表，从数据库查出

    :param demand_params: HR传入招聘需求

    :return: selected_questions 筛选出来的题目列表

    """

    target_eight = set(demand_params.get("target_eight_dim","").split(","))

    target_career21 = set(demand_params.get("target_career21","").split(","))

    need_total = int(demand_params.get("total_question_count",20))



    scored_questions = []

    for q in question_pool:

        q_eight = set(q["eight_dim_tags"].split(",")) if q["eight_dim_tags"] else set()

        q_career = set(q["career21_tags"].split(",")) if q["career21_tags"] else set()

        # 标签匹配权重打分

        score = 0

        score += ALG_CONFIG["weight_eight"] * len(q_eight & target_eight)

        score += ALG_CONFIG["weight_career21"] * len(q_career & target_career21)

        score += q["weight_score"] * ALG_CONFIG["weight_base"]

        scored_questions.append({"question":q,"match_score":score})



    # 降序排序

    scored_questions.sort(key=lambda x:x["match_score"], reverse=True)

    selected_raw = [item["question"] for item in scored_questions]



    # 题型多样性约束

    final = []

    type_counter = {"single":0,"multiple":0,"essay":0}

    for q in selected_raw:

        if len(final) >= need_total:

            break

        qt = q["question_type"]

        # 限制同题型占比，防止全部简答

        max_per_type = max(3, int(need_total * ALG_CONFIG["type_ratio"][qt]))

        if type_counter[qt] < max_per_type:

            final.append(q)

            type_counter[qt] +=1



    # 兜底：数量不足，放宽标签，直接取剩余题库填充

    if len(final) < need_total:

        remain = [x["question"] for x in scored_questions if x["question"] not in final]

        supplement = remain[: need_total - len(final)]

        final.extend(supplement)

    return final



# ===================== 模块2：测评分析引擎：八维打分 + 21职业余弦相似度匹配 =====================

def calculate_eight_dim_score(answer_records:list, question_lib:list):

    """计算八维能力0~100分"""

    dim_sum = {dim:0.0 for dim in EIGHT_DIM}

    dim_max_score = {dim:0.0 for dim in EIGHT_DIM}

    q_map = {q["id"]:q for q in question_lib}

    for ans in answer_records:

        q = q_map.get(ans["question_id"])

        if not q:

            continue

        ans_score = calc_single_question_score(q, ans["user_answer"])

        q_tags = q["eight_dim_tags"].split(",") if q["eight_dim_tags"] else []

        w = float(q["weight_score"])

        for tag in q_tags:

            if tag in dim_sum:

                dim_sum[tag] += ans_score * w

                dim_max_score[tag] += 10 * w

    #归一化0~100

    result = {}

    for d in EIGHT_DIM:

        if dim_max_score[d] ==0:

            result[d] = 0

        else:

            result[d] = round( dim_sum[d]/dim_max_score[d] * 100, 2)

    return result



def calc_single_question_score(question, user_ans):

    """单题打分，单选多选自动判分；简答返回0，标记人工复核"""

    qt = question["question_type"]

    judge = json.loads(question["judge_rule"])

    if qt in ["single","multiple"]:

        correct = set(judge["correct"])

        user = set(user_ans.split(","))

        match_rate = len(correct & user)/ max(len(correct),1)

        return match_rate * 10

    else:

        #简答题，算法只输出参考，不自动打分，报告提示人工复核

        return 0



def match_21_career(eight_dim_scores:dict):

    """基于八维分数向量，余弦相似度匹配TOP3 21型职业"""

    vec = np.array([eight_dim_scores[d] for d in EIGHT_DIM], dtype=np.float32)

    vec = vec / np.linalg.norm(vec) if np.linalg.norm(vec) !=0 else vec

    career_list = []

    for name, cv in career21_vectors.items():

        cv_np = np.array(cv, dtype=np.float32)

        cv_np = cv_np / np.linalg.norm(cv_np) if np.linalg.norm(cv_np) !=0 else cv_np

        sim = np.dot(vec, cv_np)

        career_list.append({"career_name":name,"similarity":round(float(sim),3)})

    career_list.sort(key=lambda x:x["similarity"], reverse=True)

    return career_list[:3]



def detect_risk_tip(answer_records, eight_dim_scores):

    """识别嘴炮/实干风险特征（基于调研规则库）"""

    tips = []

    # 这里规则可在配置文件维护，无需修改代码，示例规则

    if eight_dim_scores["拆解力"] <30 and eight_dim_scores["想象力"]>75:

        tips.append("风险提示：想象力强但落地拆解偏弱，需警惕偏理论、嘴炮倾向，建议面试深度追问项目落地细节")

    if eight_dim_scores["执行力"]>70 and eight_dim_scores["守护力"]>70:

        tips.append("优势：执行力与底线意识强，实干属性突出")

    return ";".join(tips)



def generate_final_suggest(top3_career, risk_tip):

    """生成一句话录用建议"""

    top1 = top3_career[0]["career_name"]

    if "风险提示" in risk_tip and "嘴炮" in risk_tip:

        return f"候选人最适配岗位类型：{top1}；存在落地能力风险，建议增加线下深度面试核验项目真实性"

    else:

        return f"候选人最适配岗位类型：{top1}；实干特质较好，推荐进入下一面试环节"



# ===================== 统一入口：答卷提交后调用主函数 =====================

def exam_analysis_main(answer_records:list, question_lib:list):

    eight_score = calculate_eight_dim_score(answer_records, question_lib)

    top3_career = match_21_career(eight_score)

    risk_tip = detect_risk_tip(answer_records, eight_score)

    final_suggest = generate_final_suggest(top3_career, risk_tip)

    return {

        "eight_dim_score": eight_score,

        "career21_result": top3_career,

        "risk_tip": risk_tip,

        "final_suggest": final_suggest

    }



if __name__ == "__main__":

    # 本地测试入口，开发调试用

    print("Algorithm module loaded successfully")

  console.log("开始执行测评任务 assignId:", assignId);

  // 1. 查询答卷记录

  const answerRecords = await db.query(`SELECT * FROM exam_answer_record WHERE assign_id = ?`,[assignId]);

  // 2. 查询关联题目

  const qIds = answerRecords.map(r=>r.question_id);

  const questionList = await db.query(`SELECT * FROM exam_official_question WHERE id IN (?)`,[qIds]);

  // 3. 调用python算法脚本，传入参数

  const inputParam = JSON.stringify({answer_records:answerRecords, question_lib:questionList});

  const cmd = `python3 exam_algorithm.py '${inputParam}'`;

  return new Promise((resolve,reject)=>{

    exec(cmd, (err,stdout,stderr)=>{

      if(err){

        console.error("算法执行错误",stderr);

        return reject(err);

      }

      const reportData = JSON.parse(stdout);

      // 4. 写入报告表 exam_report

      db.query(`INSERT INTO exam_report(assign_id,eight_dim_score,career21_result,risk_tip,final_suggest) VALUES (?,?,?,?,?)`,

        [

          assignId,

          JSON.stringify(reportData.eight_dim_score),

          JSON.stringify(reportData.career21_result),

          reportData.risk_tip,

          reportData.final_suggest

        ]

      ).then(async (insRes)=>{

        const reportId = insRes.insertId;

        // 更新分发记录，回填report_id，状态=2

        await db.query(`UPDATE exam_paper_assign SET report_id=?, status=2 WHERE id=?`,[reportId,assignId])

        resolve(reportData)

      }).catch(e=>reject(e))

    })

  })

})



// 任务入队函数，答卷提交接口调用此方法

async function addExamAnalyzeTask(assignId){

  await examQueue.add({assignId},{

    attempts:3, // 失败重试3次

    removeOnComplete:true

  })

}



// 监听任务失败

})
